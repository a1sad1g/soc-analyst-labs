# AWSRaid

## 🛡️ CyberDefenders — SOC Investigation Lab

AWSRaid is a hands-on SOC investigation lab focused on analyzing **AWS CloudTrail logs** to investigate suspicious activity within an AWS environment.

### 🎯 Objective

Investigate AWS activity, identify suspicious behavior, analyze affected resources, and reconstruct the attack activity using log analysis.

### 🛠️ Tools

* Splunk
* AWS CloudTrail
* SPL
* MITRE ATT&CK
* CyberDefenders

### 🔍 Investigation

The investigation focuses on:

* AWS API activity
* User and role activity
* Source IP analysis
* Suspicious API calls
* Cloud resource activity
* Attack timeline reconstruction

### 📂 Dataset

**Index:**

```text
aws-cloudtrail
```

**Sourcetype:**
